> 分析对象：目录 `model_code` 下的 5 个开源模型家族实现

## 二、注意力机制演进（本目录最大看点）

### 1. DeepSeek-V3：标准 MLA（Multi-head Latent Attention）
- **低秩压缩**：Q 经 `wq_a(dim→1536)` + RMSNorm + `wq_b`；KV 经 `wkv_a(dim→512+64)` 一次投影出 latent 512 + 共享 rope 64。
- **解耦 RoPE**：q/k 都拆成 nope（128 维，不做旋转）+ rope（64 维）两部分；所有头共享一份 rotary，`kv_lora_rank` 维的 latent 存 cache 而非展开的 K/V → **KV cache 从 128 头全量降到 512+64 维/位置**。
- **权重吸收（absorb）**：推理时把 `wkv_b` 吸收进 q 的 nope 分支、把 v 吸收进输出投影，注意力分数直接对 latent 计算 → 省掉逐头展开。
- 标准残差 + 前 3 层稠密 MLP、之后全 MoE；YaRN 外推至 163K。

### 2. DeepSeek-V4：压缩稀疏注意力 CSA + 重度压缩注意力 HCA（1M 上下文）
两代稀疏化的组合，注意力从"看全部"变成"滑窗 + 压缩块 + 稀疏选择"：

- **滑窗层**：`sliding_window=128`，只保留最近 128 token 的完整 KV。
- **Compressor（CSA）**：可学习**门控软池化**（`wkv`/`wgate` + softmax）把每 `compress_ratios[layer]`（4 或 128）个连续 token 压成 1 个 KV；ratio=4 时用**重叠窗口**平滑边界；压缩后 KV 再叠加上压缩位置 rope（`compress_rope_theta=160000` 独立于主 rope 10000）。
- **Indexer（稀疏选择）**：仅 ratio=4 的层挂载。它维护**自己的压缩 KV**（Hadamard 旋转 + fp4 量化），用低秩 Q 打分、ReLU 加权，`topk=512/1024` 挑出最相关的压缩块参与注意力 → 每 token 只 attend 滑窗 128 + 选出的 topk 压缩块（1M 上下文时 KV 只留约 1/10）。
- **MQA 化**：kv_heads=1、head_dim=512，KV 不再按头展开；输出侧用**分组低秩 O 投影**（`o_lora_rank=1024`、`o_groups=8/16`）压缩输出矩阵。
- **Manifold-Constrained Hyper-Connections (mHC)**：残差不再是单条，而是 `hc_mult=4` 份状态拷贝经 Sinkhorn 归一化的可学习 pre/post 权重混合（近似流形约束），替换普通残差，稳定 61 层信号传播。

### 3. GLM-5.2：MLA + DSA 稀疏注意力 + IndexShare（跨层共享 indexer）
- 注意力本体 = **DeepSeek-V3 式 MLA**（q_lora=2048、kv_lora=512、nope 192 + rope 64），但 indexer 走 DSA（DeepSeek Sparse Attention，即 V3.2 稀疏注意力路线）：
  - **轻量 indexer**：复用 MLA 的 `q_resid`（不额外投影 Q），单共享 k 头 + 可学习逐头权重 `weights_proj`，对压缩 KV 打分后 `topk=2048` 选位置，全程 `no_grad` 节省显存。
- **IndexShare 核心创新**：`indexer_types` 数组显式标注每层——前 3 层 full（自带 indexer），此后**每 4 层只放一个 full 层，其余 shared 层把上一层选出的 top-k 索引直接上抛复用**（`index_topk_freq=4`、`index_skip_topk_offset=3`）。78 层中 57 层（73%）**零 indexer 参数**，1M 上下文下每 token FLOPs 降约 2.9×。
- 双路径注意力执行：eager/SDPA 走 -inf 掩码、flash-mla 内核直接吃 int32 索引。
- RoPE 用 **interleave 模式**（相邻维度成对），且 rope_theta 高达 8M。

### 4. Kimi-K3：KDA 线性注意力 + Gated MLA 混合（DeltaNet 路线）
- **层分布**：93 层 = **69 层 KDA（线性注意力）+ 24 层 Gated MLA**（每 4 层 1 层 MLA，最后 2 层 MLA）。
- **KDA（Kimi Delta Attention）** = delta-rule 线性注意力：
  - 深度可分离**短卷积 kernel=4**（局部归纳偏置）；
  - **学习型指数衰减** `A_log`（衰减率 e⁻¹⁶~e⁻¹）+ 数据相关**写入率 beta**（sigmoid）+ 类 Mamba `dt_bias`；
  - 核内 sigmoid 门控 + **QK L2 归一化**（cosine 打分）+ 安全下限 `gate_lower_bound=-5`；
  - **全秩输出门**（`g_proj` 7168→12288）+ RMSNorm-Gated 输出；
  - **chunk（预填充，分块并行扫描）/ recurrent（解码，O(1) 状态递推）双内核** —— 这是 1M 上下文 + 高效解码的关键。
- **Gated MLA** = DeepSeek MLA + **逐（头,维）sigmoid 输出门**（`g_proj` 调制注意力输出）。
- **AttnRes（Attention Residuals）**：每 12 层一个块，用学习投影 + softmax 软选择"历史块残差 + 当前前缀和"作为跨层短路径，缓解 93 层深度问题。
- 两类注意力的状态（conv 状态 + 递归矩阵状态 vs 标准 K/V cache）由统一 `KimiDynamicCache` 管理。

### 5. Qwen3.6：Gated DeltaNet 线性注意力 + GQA Full Attention 混合
- **层分布**：`layer_types` 数组每 4 层周期 = **3 层 linear（Gated DeltaNet）+ 1 层 full**（`full_attention_interval=4`）。
- **Gated DeltaNet（NVIDIA FLA 库路线）**：
  - 深度可分离因果卷积 kernel=4（同 Mamba）；
  - **双门控**：`beta=sigmoid(b)` 控制写入（delta 规则写入门）、`g=-exp(A)·softplus(a+dt_bias)` 控制遗忘（指数衰减，Mamba 式离散化）；
  - **递归矩阵状态** `(batch, v_heads, k_dim, v_dim)`：`state = state·g + k ⊗ (β·(v − state·k))` —— 即 delta-rule 记忆矩阵（SSM 状态）；
  - QK L2 归一化、float32 数值稳定、chunked(64)/recurrent 双内核；
  - **输出门**：RMSNorm(x)·silu(gate)。
- **Full attention**：GQA（kv_heads=4/2）+ **QK-Norm**（head_dim 上 RMSNorm）+ **注意力输出 sigmoid 门**（`q_proj` 双倍输出拆出 gate）+ **partial RoPE 25%** + **interleaved M-RoPE**（11/11/10 频段交错，3D 位置编码）。
- 位置编码只作用于 full 层，linear 层完全不用 RoPE。

### 注意力路线小结

| 模型 | 注意力范式 | 长上下文手段 |
|---|---|---|
| DS-V3 | 全量 MLA | YaRN 外推 |
| DS-V4 | 滑窗 + 压缩 + 稀疏索引 (CSA/HCA) | 压缩 KV + topk 选择，1M |
| GLM-5.2 | MLA + DSA 稀疏 + **indexer 跨层共享** | 稀疏 topk + 共享，1M |
| Kimi-K3 | **线性注意力 KDA** + Gated MLA | O(1) 递归状态，1M |
| Qwen3.6 | **Gated DeltaNet 线性** + GQA full | 递归状态 + 稀疏 full 层，262K |

**核心分歧**：稀疏化路线（V4 压缩+选择、GLM 共享索引）vs 线性注意力路线（Kimi delta-rule、Qwen delta-net），二者都在压 KV cache 与注意力 FLOPs；MLA 的低秩压缩已成为各家共同底座。

## 三、MoE 路由对比

| 项目 | DS-V3 | DS-V4 | GLM-5.2 | Kimi-K3 | Qwen3.6 |
|---|---|---|---|---|---|
| 专家规模 | 256×8 | 256/384×6 | 256×8 | **896×16** | 256×8 |
| 评分函数 | sigmoid | sqrtsoftplus | sigmoid | sigmoid | softmax |
| 辅助 loss | 无 (noaux_tc) | 无 | 无 | 无 | **有 (Switch 式, 0.001)** |
| 分组 topk | 8 组选 4 | 无 | 保留结构 (n_group=1) | 保留结构 (n_group=1) | 无 |
| 选择/加权解耦 | bias 修正选择 | bias 修正选择 | `e_score_correction_bias` | `e_score_correction_bias` | 无 |
| 专家低秩化 | 无 | 无 | 无 | **LatentMoE：专家在 3584 低秩空间** | 无 |
| 特殊点 | — | **前 3 层哈希路由**（`tid2eid` token→专家表，免计算）；**FP4 专家**；SwiGLU 幅值截断 (`swiglu_limit`) | 融合 gate_up 3D 权重 | 2 共享专家；仅专家 FFN 走 MXFP4 | 融合 gate_up 3D 权重；**共享专家配标量 sigmoid 门** |

**要点**：
- 除 Qwen 外全部走 **DeepSeek 无 aux loss 路线**（sigmoid + bias 解耦选择与加权 + 归一化）；Qwen 保留 softmax + Switch aux loss 传统。
- Kimi 的 **Stable LatentMoE** 是最激进的：896 专家 × top-16 + 专家低秩化 + MXFP4 量化，README 称相对 K2 有 ~2.5× 规模效率提升。
- DS-V4 的**哈希路由**（前 3 层用 token id 查表确定专家，完全免去门控计算）与 **FP4 专家**（专家权重 4bit，其余 FP8）是独有的工程化压缩。

## 四、其他结构差异

### 残差/连接
- DS-V3、Qwen：标准 pre-norm 残差。
- DS-V4：**Hyper-Connections**（多状态拷贝 + Sinkhorn 混合）。
- GLM：标准残差 + 稀疏注意力。
- Kimi：标准残差 + **AttnRes 跨层软残差**（每 12 层）。

### 激活函数
- DS-V3/V4、GLM、Qwen：标准 SiLU (SwiGLU)。
- Kimi：**SiTU-GLU** —— `beta·tanh(gate/beta)·sigmoid(gate)`，用软饱和 tanh 替换 SiLU 的无界线性门，激活幅值有界（beta=4），配合 `linear_beta=25` 软裁剪 up 分支，稳定 93 层训练。

### 位置编码
- DS-V3：YaRN (factor 40)。
- DS-V4：双 rope 体系 —— 主 rope(θ=10000) + 压缩位置 rope(θ=160000)。
- GLM：rope θ=8M，interleave 模式（奇偶切片直接旋转）。
- Kimi：标准 RoPE（MLA 共享 rotary + KDA 无 RoPE）。
- Qwen：**partial rotary 25% + interleaved M-RoPE**（文本 T/H/W 三维，视频按时间戳切段）。

### 多模态
- Kimi-K3：**原生多模态** —— MoonViT-V2 视觉塔（NaViT 动态分辨率、divided_fixed 位置编码、sd2_tpool 时空合并）+ PatchMergerMLPV2 投影，LLaVA 式占位符替换。
- Qwen3.6：**3D 时空 patch**（Conv3d，temporal=2）+ 27 层 ViT + 2×2 merger，`get_rope_index` 生成 3D position ids，视频按时间戳拆分。
- DS/GLM：纯文本。

### MTP（Multi-Token Prediction，投机解码加速）
- DS-V4、GLM-5.2：1 层 MTP 完整实现（GLM 还专门优化 MTP 以提升投机解码接受率）。
- DS-V3、Qwen：配置声明 `num_nextn_predict_layers=1`/`mtp_num_hidden_layers=1`，但本地建模文件未实现（权重由外部推理引擎如 vLLM 的 speculative 配置接管）。
- Kimi-K3：无 MTP。

## 五、五家技术路线一图流

```
DeepSeek：全量 MLA ──V3──▶ 稀疏压缩注意力 CSA/HCA + Hyper-Connections + FP4 ──V4
                              （"把注意力变稀疏、把权重变低比特"）

GLM    ：MLA + DSA 稀疏 ──▶ IndexShare 跨层共享 indexer（73% 层零参数）
                              （"让稀疏索引算一次、大家复用"）

Kimi   ：Delta-Rule 线性注意力 KDA + Gated MLA + LatentMoE(896) + SiTU + AttnRes
                              （"把注意力变递归状态、把 MoE 做到极致稀疏"）

Qwen   ：Gated DeltaNet 线性注意力 + GQA full + partial M-RoPE + aux-loss MoE
                              （"线性注意力工业化落地 + 多模态 3D 位置"）
```

## 六、结构演进的共同趋势（对照标准 Transformer）

1. **注意力不再全量**：从"每个 token 看全部上下文"演进为"滑窗 + 压缩块 + 稀疏 topk 选择"（DS-V4、GLM）或"递归状态线性注意力"（Kimi、Qwen），目标都是 **1M 上下文 + 线性/亚线性复杂度**。
2. **KV 缓存极致瘦身**：MLA 低秩压缩（DS/GLM/Kimi）→ 压缩 token（DS-V4）→ 矩阵状态 O(1)（Kimi/Qwen）→ 单 KV 头 MQA（DS-V4）。
3. **MoE 越做越稀疏、越做越省**：专家数量 256→896、激活比例 8/256→16/896；配合专家低秩化（Kimi）、FP4/MXFP4 量化（DS-V4/Kimi）、哈希路由免算（DS-V4）。
4. **残差连接被重新设计**：Hyper-Connections（DS-V4）、AttnRes（Kimi）——深度增大后普通残差不够用。
5. **MTP 多 token 预测普及**：用于投机解码降延迟（DS-V4、GLM）。
6. **原生多模态成标配**：Kimi、Qwen 把视觉编码器直接并入 LLM 主干，共享位置编码体系。
7. **量化进训练**：从训练后 FP8 量化（DS-V3）到 QAT 的 FP4/MXFP4（DS-V4、Kimi），低比特成为规模扩张的杠杆。
